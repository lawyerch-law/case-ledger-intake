# 金山-律师案件管理录入技能

把律师"脑子里的案情"用大白话讲出来，AI 自动解析成台账字段并写回金山多维表。7 阶段覆盖（委托/立案/开庭/保全/判决/执行/结案），自动推算诉讼时效、查漏补缺、极简单表输出。

> 输出为律师工作草稿，非法律意见。

## 安装（3 步）

**① 连接金山文档**：在 WorkBuddy 连接器管理中启用并授权 **kdocs（金山文档）** 连接器。

**② 复刻作者台账模板**（新用户必做，已有台账的老用户跳过）：
- 方式 A（AI 代劳）：对 AI 说"帮我从 https://www.kdocs.cn/l/cubUxHzlKoTl 复刻《律师个人案件管理台账》到我的云文档并绑定"
- 方式 B（手动）：浏览器打开上述链接 → 右上角"另存到我的云文档" → 完成后告诉 AI 已复刻

**③ 安装技能**：

```bash
git clone https://github.com/BluerAngala/case-ledger-intake.git ~/.workbuddy/skills/case-ledger-intake
ls ~/.workbuddy/skills/case-ledger-intake/SKILL.md   # 验证结构
```

**前置条件**：WorkBuddy + kdocs 连接器已连接 + 金山多维表台账（新用户按 ② 复刻作者模板；老用户用自己的台账）。

**自动绑定**：首次使用 AI 检索你的台账——找到则直接绑定；找不到则走「模板复刻」路径（AI 从作者模板链接 `save_as_file` 复制到你的云盘）→ 本地生成 `config.json`（私有，不入库）→ 动态解析表/字段/视图 → 开始录入。

## 使用示例（对话实录风格）

### 示例 1｜录新案子（民间借贷，委托阶段）

**你说**：帮我录一个新案子。我朋友 X 先生借了 30 万元给 Y 先生，2023 年 1 月打的借条，说好 2023 年 6 月底还，到现在一分没还，电话不接。我想帮他起诉。收费打算收 1 万，还没签委托合同。

**AI 会**：
1. 判定委托阶段 → 解析：原告 X 先生、被告 Y 先生、案由民间借贷（推断）、一审（推断）
2. **推算时效**：2023-06-30 到期 + 3 年 = 2026-06-30 截止 → ⚠️ 已过期，追问有无中断证据
3. 你答"2025-01-03 微信催收过" → 中断重算，截止 **2028-01-02**，风险解除
4. 确认推断项 → 写回主表 + 收费记录表 → 回读验证 → 复述结论

### 示例 2｜案件立案了（补记，立案阶段）

**你说**：X 先生的买卖合同案立案了。某某区法院，案号（2026）粤01民初XXXX号，8月30号立案。对方答辩期到9月18号，举证期限9月20号。诉讼费交过了，材料都齐了。

**AI 会**：回填案号/立案日期/审理机关 → **登记期限提醒**（答辩期 09-18、举证期 09-20，提醒日期直接填）→ 动作检查（管辖核对/材料挂关联/诉讼费）→ 写回。

### 示例 3｜紧急应诉（我方为被告）

**你说**：我们被告了，刚收到起诉状，传票写的 10 月 10 号开庭。

**AI 会**：置顶"⚠️ 紧急：答辩期 X 日前 / 开庭 10-10" → 先问受理法院、答辩期是否已过 → 提示立即调卷/答辩 → 登记期限提醒 → 台账照录。

### 示例 4｜查漏补缺（检查字段是否齐备）

**你说**：帮我看看〔案件名〕现在还缺什么。

**AI 会**：对照该阶段视图白名单 → 输出单表（✅ 已录 / ⚠️ 待确认 / ❌ 缺失）→ 只追问缺失的 P0 必填 → 补齐写回。
