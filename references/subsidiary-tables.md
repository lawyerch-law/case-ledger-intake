# 子表使用指南：期限提醒 / 收费记录 / 流程节点 / 人员信息（v1，2026-08-26）

> ⚠️ 字段以运行时 schema 为准；本文件说明**每张表是什么、什么时候用、怎么用、注意事项**。

## 一、期限提醒表(11)

**是什么**：法定期限/关键日期的提醒登记表。律师侧自动化流程按「提醒日期」字段触发提醒。

**什么时候用**：
| 场景 | 期限类型 | 示例 |
|---|---|---|
| 立案后答辩/举证 | 答辩期限 / 举证期限 | X 案答辩期 9/18 |
| 开庭传票 | 其他（备注"开庭传票"） | X 案 10/10 开庭 |
| 财产保全 | 保全期限 / 续保期限 | 存款冻结至 2027-10-09 |
| 判决后 | 上诉期限 | 送达日+15 日 |
| 其他要盯的日期 | 其他 | 调解履行日、续约日 |

**怎么用**：每条期限一条记录，Link 挂主表案件。截止日期 = 法定最后一天；**提醒日期直接填触发提醒的日期**（2026-08-26 律师定稿：无"提前几天"概念）；状态 未提醒/已提醒/已完成，由自动化流程推进。

**注意事项**：
- 提醒日期直接填，不要算提前天数
- 一案件可多条期限记录，类型不重复
- 开庭提醒：类型"其他"+备注"开庭传票"（期限类型无"开庭"选项）
- 保全续保：类型"续保期限"，届满前 30 天起关注
- 错过登记 = 失权（答辩/举证/上诉都是严格法定期限）

## 二、收费记录表(12)

**是什么**：收费明细表。主表「应收总额/实收总额」是 Lookup 自动汇总，不手填。

**什么时候用**：委托阶段谈好收费后建第一条；每次收款、开票、变更时更新。

**怎么用**：收费项目（前期代理费/风险代理费/差旅费…）+ 应收金额 + 实收金额 + 收款日期 + 收款方式（转账/现金）+ 开票状态 + 备注；「关联案件」Link 挂主表。

**注意事项**：
- **收费确认制（铁律）**：只问不拆、说了才记；口径模糊（基数按多少）必追问
- **只有代理费进收费记录**；客户被欠的货款/案款 ≠ 代理费，写案情摘要/备注
- 主表不手填金额，应收/实收是自动汇总
- **Link 字段写入坑（实测）**：值传数组 `["主表记录id"]` + 调用带 `link_value="id"`，传裸字符串报错
- Lookup 汇总异步刷新，回读可能暂显 0，属正常

## 三、流程节点表(15)

**是什么**：法定期限知识库（42 条），按案件类型分组的节点模板：节点名称、法定时限、起算规则、法律依据。

**什么时候用**：推算诉讼时效/期限时作为权威依据（本技能推算时效即参考它）；律师自查某个期限算得对不对时。

**怎么用**：只读查询——按案件类型找对应节点，取其法定时限/起算规则。

**注意事项**：
- 是**知识库**不是案件数据，一般只读不改
- 与法律常识配合使用（如民诉法解释 487 条保全期限、民诉法 171 条上诉期）
- 推算时效时：起算日 + 年数 − 1 天 = 截止日；注意时效中断（还款/承诺/催款重新起算）

## 四、人员信息表(8)

**是什么**：人员通讯录（委托人、当事人、对方、法官/证人等的姓名/角色/联系方式）。

**什么时候用**：记录办案相关人员的联系信息；找联系人电话/地址时。

**怎么用**：人员登记（姓名/角色/电话/单位/备注）。**当前与案件表未关联**（独立通讯录），如需挂案件可后续加 OneWayLink。

**注意事项**：
- 未关联案件：查某人名下有哪些案子需手动检索
- 含个人隐私（身份证号/住址/电话），**注意保密**，不外传
- 法官/书记员电话：开庭传票信息优先记开庭记录子表(16)，人员信息表可存法官库备查
