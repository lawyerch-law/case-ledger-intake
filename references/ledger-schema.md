# 台账结构与字段清单（2026-08-26 定稿）

> ⚠️ **本文件为结构快照（业务参考），运行时以 get_schema 动态解析为准**：表名→sheet_id、字段名→ID、视图名→显示字段集均从实际 schema 读取；阶段字段白名单以对应阶段视图 `hidden=false` 字段为单一事实源，本文件字段 ID 映射仅用于快速参考，写入字段名与 schema 不一致时以 schema 为准。

文件：`律师个人案件管理台账(公开展示).dbt`（文件名可在首次绑定时改名）
file_id：**一律以技能目录 `config.json` 为准**；分享版不含 file_id（个人绑定数据，见 SHARE.md）

## 表关系

```
案件总台账(4) ──Link──> 办案记录(5)
     │  ├──OneWayLink──> 收到材料(9)   （"关联：收到材料"）
     │  ├──Link──> 期限提醒(11)
     │  ├──Link──> 收费记录(12)        （应收/实收 Lookup 汇总回主表）
     │  └──Link──> 开庭记录(16)
人员信息(8) = 通讯录，暂未关联案件
流程节点(15) = 42 条法定期限知识库，按案件类型分组
我方文书(13) = 文书库，注意：当前缺「关联案件」字段（断链，待修复）
```

## 子表字段

**收费记录(12)**：关联案件(Link) · 收费项目 · 应收金额 · 实收金额 · 收款日期 · 收款方式 · 开票状态 · 备注

**收到材料(9)**：创建时间 · 关联案件(OneWayLink→主表) · 文件附件 · 材料名称 · 备注 · AI识别证据 · 材料标签

**办案记录(5)**：时间 · 事项 · 办理进度(已完成/未完成) · 附件 · 备注 · 关联案件(Link) · 完成时间

**期限提醒(11)**：关联案件(Link) · 期限类型 · 截止日期 · 提醒日期 · 状态(未提醒/已提醒/已完成) · 备注
> 2026-08-26 律师定稿：原「提前提醒天数」(Number, id B4) 已删除，改为「提醒日期」(Date, id DG)——录入时直接填提醒日期，自动化流程由律师侧自行配置。

**开庭记录(16)**：关联案件(Link) · 开庭时间(Date) · 庭次 · 开庭地点 · 联系电话 · 庭审事项 · 庭审结果 · 备注
> 2026-08-26 律师定稿：开庭传票信息（开庭时间/地点/联系电话）归位于本子表；主表曾临时新增的开庭时间(DI)/地点(DJ)/电话(DK)字段已删除回滚。

**流程节点(15)**：案件类型 · 节点名称 · 法定时限 · 起算规则 · 法律依据 · 备注（42 条模板，时效推算的权威依据）
