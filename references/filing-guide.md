# 立案阶段：对话采集指南（v1，2026-08-26）

## 阶段定位

立案阶段 = 搞清楚"**案子上没上、立案信息齐不齐**"。重点三件事：
① 管辖对不对（被驳回/移送了没）② 案号/立案日期/审理机关回填了没 ③ 答辩期/举证期登记了没。

**技能定位不变**：录入即查漏补缺 + 风险防控。立案阶段最高风险 = **应诉期限错过**（答辩期 15 日、举证期）——漏登记 = 失权。

## 问题库（一次 1-2 问，P0 优先）

### P0-1 立案进展
> "案子立案了吗？收到受理通知书/案号了吗？"

### P0-2 立案三要素（回填）
> "案号是多少？立案日期是哪天？哪个法院受理的？"
- 提示核对：审理机关字段的默认值（律师画像中的默认审理机关）是否与实际管辖一致

### P0-3 应诉期限（我方为被告时最高优先）
> "收到起诉状副本/应诉通知书了吗？答辩期、举证期限到哪天？"
- 立案后立即在期限提醒表(11)登记：答辩期（收到副本+15 日）/举证期，提醒日期直接填（不填提前天数）

### P1-4 缴费与材料
> "诉讼费缴费通知收到了吗？立案材料（起诉状/证据/主体材料）齐了吗？"

## 动作检查表（立案阶段该做没做）

| # | 动作 | 怎么确认 | 漏了的后果 |
|---|---|---|---|
| 1 | 案号/立案日期回填 | 主表立案字段是否填写 | 台账断链，后续阶段无从追踪 |
| 2 | 管辖核对 | 审理机关与实际受理法院一致 | 立案被驳回/移送，白排队 |
| 3 | 答辩期/举证期登记 | 期限提醒表有无记录 | **错过答辩/举证 = 失权，执业事故** |
| 4 | 材料挂「关联：收到材料」 | 子表有无关联记录 | 立案被退回 |
| 5 | 诉讼费缴纳 | 缴费通知/回执 | 按撤诉处理 |
| 6 | 时效复核 | 立案日期 < 诉讼时效截止日 | 时效抗辩风险 |

## 输入模板示例（某买卖合同案）

**律师典型输入**（立案后）：
> "某律师，X 先生那单买卖合同案立案了。某某区人民法院，案号（2026）粤01民初XXXX号，8月30号立案。对方答辩期到9月18号，举证期限9月20号。法院让交诉讼费，我这边已经交过了。材料都齐了。"

**技能解析（三态）**：
- ✅ 明确：案号（2026）粤01民初XXXX号、立案日期 2026-08-30、审理机关 某某区人民法院、答辩期至 2026-09-18、举证期至 2026-09-20、诉讼费已交、材料已齐
- ⚠️ 推断：无（本案全部明确；若缺审理机关则默认值需确认）
- ❌ 缺失：无（若律师未提缴费/材料 → 标缺失并追问）

**单表输出**（立案阶段视图字段）：

| 台账字段 | 级别 | 状态 | 当前值 | 说明 |
|---|---|---|---|---|
| 案号 | P0 | ✅ | (2026)粤01民初XXXX号 | 立案回填 |
| 立案日期 | P0 | ✅ | 2026-08-30 | 立案回填 |
| 审理机关 | P0 | ✅ | 某某区人民法院 | 与默认值一致 |
| 期限提醒 | P0 | ⚠️ | 答辩期 09-18 / 举证期 09-20 | 待登记期限提醒表(11) |
| 关联：收到材料 | P1 | ✅ | 已齐 | 待挂子表 |
| 备注 | P1 | ✅ | 诉讼费已交 | 可写办案记录 |
| …（其余字段沿用委托阶段已录值） | | | | |

**写回动作**：
1. `update_records`(sheet 4, 目标记录 id)：案号、立案日期、审理机关
2. `create_records`(sheet 11 期限提醒)：答辩期、举证期，提醒日期直接填（不填提前天数），Link 挂主表记录 id（数组 + link_value="id"）
3. 材料已齐 → 律师手动补挂「关联：收到材料」或告知附件名后代录
4. 诉讼费已交 → 办案记录(5)记一条
5. 回读验证

## 铁律（沿用委托阶段 + 立案补充）

- 我方为被告时，**答辩期/举证期登记优先于一切**（期限提醒表）。
- 案号/立案日期必须律师提供，不得推断编造。
- 审理机关以实际受理法院为准，默认值仅作参考，必须核对。
- 其余沿用 SKILL.md 铁律：三态标注、单表输出、防串场、字段名与 schema 一致。
